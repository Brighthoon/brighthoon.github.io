Pipeline Project Overview

파이프라인 구축 및 자동화와 관련된 내용들을 정리하는 공간입니다.

1. 워크플로우 (Workflow)

  1. 영상 입력 및 배경 확보: 영상의 초기 프레임 또는 배경 추출 알고리즘을 사용하여 홀드가 모두 보이는 이미지를 확보.
    • 랜덤 프레임들에 대해 중앙값 필터(Median filter) 사용예정. 추출 방식에 대해서는 연구 필요.
  2. 홀드 세그멘테이션 (Instance Segmentation): 확보된 이미지에서 YOLO (또는 YOLO-World + SAM)를 사용하여 각 홀드의 Bbox와 Pixel-level Mask(Polygon)를 추출합니다.
    • 모델이 홀드를 인식할지 안할지 확실하지가 않아, 초기 데이터는 사람이 해야할수도 있음.
  3. 등반가 추적 및 포즈 추론 (Pose Estimation + Tracking): 영상에서 Multi-Object Tracking을 통해 사람을 특정하고, 관절 좌표 시퀀스를 추출.
  4. 상호작용 분석: 추출된 홀드 마스크와 관절 좌표의 충돌(Intersection) 및 체류 시간을 분석하여 사용한 홀드 ID 리스트를 생성합니다.

2. 학습 모델

  • Instance Segmentation 모델: 홀드 탐지 전용. 초기에는 YOLO-World/SAM 등으로 자동 라벨링 후 커스텀 학습(Fine-tuning) 진행.
  • Pose Estimation 모델: YOLO Pose 모델을 기본으로 하며, 암벽 등반 특유의 신체 가림 현상을 보정하기 위한 Tracking 알고리즘 포함.

3. 데이터베이스 (DB) 설계

데이터 엔지니어링 효율성과 AI 모델 버전 관리를 위해 메타데이터 DB와 파일 시스템 테이블은 분리.

from sqlalchemy import Column, String, DateTime, ForeignKey, Boolean
from sqlalchemy.orm import relationship
from datetime import datetime

class ClimbingProblem(Base):
    """
    원본 영상 및 암장 메타데이터 관리 테이블
    """
    __tablename__ = 'climbing_problems'

    id = Column(String, primary_key=True)      # PRB-0001 (UUID 또는 Hash)
    
    # 1. 메타데이터 (사람이 입력하거나 외부 API 연동)
    gym_name = Column(String)                  # 암장 이름
    difficulty = Column(String)                # 난이도 (V5, 파랑 등)
    
    # 2. 파이프라인 및 원본 파일 정보
    status = Column(String, default="PENDING") # PENDING, PROCESSING, COMPLETED, FAILED
    base_folder_path = Column(String)          # 데이터가 저장될 루트 폴더 경로
    video_filename = Column(String)            # 원본 영상 파일명
    
    # 3. 시간 정보
    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

    # 1:N 관계 (하나의 영상에 여러 모델 추론 결과 존재 가능)
    inference_results = relationship("InferenceResult", back_populates="problem")

class InferenceResult(Base):
    """
    AI 모델 버전별 추론 결과(JSON) 관리 테이블
    """
    __tablename__ = 'inference_results'

    id = Column(String, primary_key=True)      # INF-0001
    problem_id = Column(String, ForeignKey('climbing_problems.id'))
    
    # 1. 모델 정보 및 파일 경로
    model_version = Column(String)             # 예: 'v1.5-custom-hold'
    hold_json_filename = Column(String)        # 예: 'holds_v1.5.json'
    pose_json_filename = Column(String)        # 예: 'poses_v1.5.json'
    
    # 2. 상태 관리 (버전 관리의 핵심)
    is_active = Column(Boolean, default=False) # 현재 대표 데이터 여부
    
    # 3. 시간 정보
    created_at = Column(DateTime, default=datetime.utcnow)

    problem = relationship("ClimbingProblem", back_populates="inference_results")
